%--- Problem 2: Theatre seating model; first row exceeding 65 seats [6 marks] ---
%--- Source: Original (freshly authored, AA SL 1.2); from 1-3CW_Arithmetic-sequences-continued P2 ---
\item[2.] [Maximum mark: 6]

A theatre has rows of seats. The first row has $18$ seats. Each row
after the first has $3$ more seats than the row in front of it. The
number of seats in row $n$ is $u_{n}$.

\begin{enumerate}[itemsep=0.1cm]
  \item Find an expression for $u_{n}$ in terms of $n$. \hfill [2]
  \item Find the number of seats in row $12$. \hfill [1]
  \item Find the number of the first row that has more than $65$
  seats. \hfill [3]
\end{enumerate}

that, he saves \$2 more than he saved the week before.

\begin{enumerate}[itemsep=0.1cm]
  \item Find the amount Luca saves in week $12$. \hfill [2]
  \item Find the total amount Luca has saved by the end of week $12$.
  \hfill [2]
  \item Find the first week when Luca's total savings are more than
  \$200. \hfill [3]
\end{enumerate}
