\item[1.]

Consider the sequence
$$7,\; 11,\; 15,\; 19,\; \ldots$$

\begin{enumerate}[itemsep=0.1cm]
  \item Write down the value of $u_{1}$, the first term.
  \item State whether the sequence is arithmetic. Give a reason for
  your answer.
  \item Write down the value of the common difference $d$.
  \item Write down the next two terms of the sequence.
  \item Find an expression for $u_{n}$, the $n^{\text{th}}$ term.

  \item Find $u_{50}$.
\end{enumerate}
