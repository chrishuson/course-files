\item[2.]

A theatre has rows of seats. The first row has $18$ seats. Each row
after the first has $3$ more seats than the row in front of it. The
number of seats in row $n$ is $u_{n}$.

\begin{enumerate}[itemsep=0.1cm]
  \item Find an expression for $u_{n}$ in terms of $n$.
  \item Find the number of seats in row $12$.
  \item Find the number of the first row that has more than $65$
  seats.
\end{enumerate}
