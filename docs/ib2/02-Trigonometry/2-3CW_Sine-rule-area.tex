\begin{center}
\fbox{\begin{minipage}{0.9\textwidth}
\centering
In triangle $ABC$, side $a$ is opposite angle $A$, side $b$ is opposite
angle $B$, and so on.
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}
\qquad\qquad
\text{Area} = \frac{1}{2}ab\sin C$$
\end{minipage}}
\end{center}
