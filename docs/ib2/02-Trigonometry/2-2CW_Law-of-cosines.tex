\begin{center}
\fbox{\begin{minipage}{0.9\textwidth}
\centering
In triangle $ABC$, side $a$ is opposite angle $A$, side $b$ is opposite
angle $B$, and so on.
$$c^{2} = a^{2} + b^{2} - 2ab\cos C
\qquad\qquad
\cos C = \frac{a^{2} + b^{2} - c^{2}}{2ab}$$
\end{minipage}}
\end{center}
