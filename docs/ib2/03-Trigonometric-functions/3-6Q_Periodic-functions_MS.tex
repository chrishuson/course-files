\subsubsection*{3.6 Quiz: Periodic Functions --- Markscheme}

\textbf{\large Version (a)}

\emph{Total: 40 marks. Problems 1 and 2 are without a calculator: exact
answers are required. In Problems 3 and 4, accuracy marks need 3 s.f., the
exact value, or the calculator display with an ellipsis; a value cut short
with no ellipsis earns A0 (markscheme-spec \S21). Problem 3 needs degree
mode and Problem 4 radian mode: a value worked in the wrong mode earns the
method marks only.}

\begin{enumerate}[itemsep=0.3cm]

%--- Problem 1: Graph of f(x) = 3sin(2x) - 2; dashed g = f(x + pi/4) [9 marks] ---
\item[1.] [Maximum mark: 9]

$f(x) = a\sin(bx) + d$; maximum $\left(\frac{\pi}{4}, 1\right)$, minimum
$\left(\frac{3\pi}{4}, -5\right)$; $g$ is $f$ translated $\frac{\pi}{4}$ to
the left.

\textbf{(a)} maximum value $= 1$ \hfill \textbf{A1}

minimum value $= -5$ \hfill \textbf{A1}

\emph{Write down: a bare answer earns the marks. Accept the points
$\left(\frac{\pi}{4}, 1\right)$ and $\left(\frac{3\pi}{4}, -5\right)$.}

\textbf{(b)} period $= \pi$ \hfill \textbf{A1}

\emph{Wrong methods, each A0: $\frac{\pi}{2}$ (maximum to minimum is half a
period); $2\pi$ (the period of $\sin x$).}

\textbf{(c)} $a = \dfrac{1 - (-5)}{2}$ \ or \ $d = \dfrac{1 + (-5)}{2}$
\hfill \textbf{M1}

$a = 3$ \hfill \textbf{A1}

$d = -2$ \hfill \textbf{A1}

$b = \dfrac{2\pi}{\pi} = 2$ \hfill \textbf{A1}

\emph{M1 for either formula, or for reading the principal axis $y = -2$
from the graph. Correct $a$ and $d$ with no working earn M0A1A1. A bare
$b = 2$ earns its A1. Wrong methods: $a = 6$ (maximum minus minimum);
swapping $a$ and $d$ ($a = -2$, $d = 3$); $b = \pi$ (the period used as
$b$) or $b = \frac{1}{2}$: A0 for that value. FT $b$ from the candidate's
period in (b).}

\textbf{(d)} The maximum of $f$ at $x = \frac{\pi}{4}$ is at $x = 0$ on the
graph of $g$: the graph has moved $\frac{\pi}{4}$ to the left, and
$f(x + h)$ is a translation to the left by $h$. \hfill \textbf{R1}

$g(x) = f\!\left(x + \dfrac{\pi}{4}\right)$ \hfill \textbf{A1}

\emph{R1 for any valid reason: the graph moves left; a point of $f$ appears
$\frac{\pi}{4}$ earlier on $g$; or a check such as
$g(0) = f\!\left(\frac{\pi}{4}\right) = 1$. Do not award R0A1: the choice
with no reason earns 0. Wrong method: $f\!\left(x - \frac{\pi}{4}\right)$
(a minus sign for a move to the left): R0A0.}

\textbf{(c)} $315 \times \dfrac{\pi}{180} = \dfrac{7\pi}{4}$ \hfill \textbf{A1}

\emph{Accept $\frac{315\pi}{180}$ or $1.75\pi$. $5.50$ is not a multiple

\textbf{(d)} $Q\left(\cos 315^\circ,\ \sin 315^\circ\right)

\textbf{(f)} $\tan\theta = \dfrac{\sin\theta}{\cos\theta} =

\emph{Accept $-\frac{2\sqrt{5}}{5}$. FT from the candidate's $\cos\theta$

\hfill \textbf{A1}

\newpage

\textbf{(f)} $2.65\sin\!\left(\dfrac{2\pi}{365}(t - 80.75)\right) + 12.15 = 10$
\hfill \textbf{M1}

\textit{GDC: graph $y = P(t)$ and $y = 10$ for $0 \le t \le 365$; find both

$t = 25.8$ \ ($25.7716\ldots$) \ and \ $t = 318$ \ ($318.228\ldots$)
\hfill \textbf{A1}

$P(t) < 10$ from $t = 318.228\ldots$ to the end of the year and from the

$(365 - 318.228\ldots) + 25.7716\ldots = 72.5$ days \quad ($72.5433\ldots$)
\hfill \textbf{A1}

\emph{M1 for the equation, or a graph with $y = 10$ drawn. The first A1
needs both values. Accept $72.3$ from $b = 0.0172$, and any value
consistent with the candidate's rounded intersections. Wrong method:
$318.228\ldots - 25.7716\ldots = 292$ days (the time with \emph{more} than

final A0 with a feedback note to give 3 s.f. FT from the candidate's
model.}
