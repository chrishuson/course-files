Solutions
  Problem 1 — Line through two points:
  - (a) m = (-1 - 5)/(4 - (-2)) = -6/6 = -1
  - (b) y - 5 = -1(x + 2) -> y = -x + 3
  - (c) 0 = -x + 3 -> x = 3. x-intercept: (3, 0)
  - (d) Parallel: m = -1, through (0, 7): y = -x + 7

  Problem 2 — Quadratic factoring:
  - (a) f(x) = (x - 6)(x + 2)
  - (b) x = 6 and x = -2
  - (c) Axis: x = 4/2 = 2. f(2) = 4 - 8 - 12 = -16. Vertex = (2, -16)
  - (d) f(0) = -12. y-intercept: (0, -12)
  - (e) f(x) >= -16

  Problem 3 — Perpendicular lines:
  - (a) y = -2x + 8
  - (b) Gradient = -2, y-intercept = 8
  - (c) Perp gradient = 1/2. y + 1 = 1/2(x - 2) -> y = 1/2 x - 2 -> x - 2y - 4 = 0
  - (d) -2x + 8 = 1/2 x - 2 -> -4x + 16 = x - 4 -> 5x = 20 -> x = 4, y = 0. Point (4, 0)

  Problem 4 — Vertex form:
  - (a) g(x) = 2(x^2 - 4x) + 6 = 2(x^2 - 4x + 4) - 8 + 6 = 2(x - 2)^2 - 2
  - (b) Vertex = (2, -2)
  - (c) 2(x - 2)^2 = 2 -> (x - 2)^2 = 1 -> x = 1 or x = 3
  - (d) y = -g(x) = -2x^2 + 8x - 6
