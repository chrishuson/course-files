%--- Problem 3: Tangent + product rule [5 marks] ---
\item[3.] [Maximum mark: 5]

$y = (2x-1)\mathrm{e}^{kx}$

$y' = 2\mathrm{e}^{kx} + (2x-1) \cdot k\mathrm{e}^{kx}$ \hfill \textbf{M1A1}

At $x = 1$: $y' = 2\mathrm{e}^{k} + k\mathrm{e}^{k} = (2+k)\mathrm{e}^{k}$ \hfill \textbf{A1}

Tangent parallel to $y = 5\mathrm{e}^{k}x$, so slope $= 5\mathrm{e}^{k}$:

$(2+k)\mathrm{e}^{k} = 5\mathrm{e}^{k}$ \hfill \textbf{M1}

$k = 3$ \hfill \textbf{A1}
