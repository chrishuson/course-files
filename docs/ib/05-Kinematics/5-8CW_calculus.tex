Solutions
  Problem 1 — f(x) = x³ - 3x + 2:
  - (a) f'(x) = 3x² - 3
  - (b) f'(2) = 3(4) - 3 = 9
  - (c) f(2) = 8 - 6 + 2 = 4. Tangent: y - 4 = 9(x - 2) → y = 9x - 14
  - (d) f'(x) = 0: 3x² - 3 = 0, x² = 1, x = ±1
        f(1) = 1 - 3 + 2 = 0 → (1, 0)
        f(-1) = -1 + 3 + 2 = 4 → (-1, 4)

  Problem 2 — f(x) = 3x² - 6x:
  - (a) ∫(3x² - 6x)dx = x³ - 3x² + c
  - (b) f(0) = 0. f(2) = 12 - 12 = 0. ✓
  - (c) [x³ - 3x²]₀² = (8 - 12) - 0 = -4. Area = |-4| = 4
  - (d) g(x) = x³ - 3x² + c. g(1) = 1 - 3 + c = 5 → c = 7. g(x) = x³ - 3x² + 7

  Problem 3 — Normal + Binomial:
  - (a)(i) X ~ B(3, 1/3)
  - (a)(ii) P(X=0) = (2/3)³ = 8/27. P(X=1) = 3(1/3)(2/3)² = 12/27.
            P(X ≤ 1) = 20/27
  - (b)(i) z = (56-50)/σ = 2. σ = 3
  - (b)(ii) z = (44-50)/3 = -2. P(Z < -2) = P(Z > 2) = 0.0228

  Problem 4 — f(x) = x³ - 6x² + 9x + 1:
  - (a) f'(x) = 3x² - 12x + 9
  - (b) 3x² - 12x + 9 = 0 → x² - 4x + 3 = 0 → (x-1)(x-3) = 0 → x = 1, x = 3
  - (c) f''(x) = 6x - 12. f''(1) = -6 < 0 → local max. f''(3) = 6 > 0 → local min.
  - (d) f(1) = 1 - 6 + 9 + 1 = 5. f(3) = 27 - 54 + 27 + 1 = 1.
        Local max at (1, 5). Local min at (3, 1).
