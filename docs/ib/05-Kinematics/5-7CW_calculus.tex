Solutions
  Problem 1 — f(x) = x³ - 4x + 1:
  - (a) f'(x) = 3x² - 4
  - (b) f'(2) = 3(4) - 4 = 8
  - (c) f(2) = 8 - 8 + 1 = 1. Tangent: y - 1 = 8(x - 2) → y = 8x - 15
  - (d) f'(x) = 0 → 3x² = 4 → x = ±2/√3 = ±2√3/3
        f(2/√3) = 8/(3√3) - 8/√3 + 1 = 1 - 16√3/9
        f(-2/√3) = -8/(3√3) + 8/√3 + 1 = 1 + 16√3/9

  Problem 2 — f(x) = 6x² - 2x:
  - (a) ∫(6x² - 2x)dx = 2x³ - x² + c
  - (b) [2x³ - x²]₁² = (16 - 4) - (2 - 1) = 12 - 1 = 11
  - (c) g(x) = 2x³ - x² + c. g(1) = 2 - 1 + c = 7 → c = 6.
        g(x) = 2x³ - x² + 6

  Problem 3 — f(x) = (2x + 1)eˣ:
  - (a) Product rule: f'(x) = 2eˣ + (2x + 1)eˣ = (2x + 3)eˣ
  - (b) f(0) = 1·1 = 1, f'(0) = 3·1 = 3. Tangent: y = 3x + 1
  - (c) 0 = 3x + 1 → x = -1/3. A = (-1/3, 0)
  - (d) f'(x) = 0 → (2x + 3)eˣ = 0 → x = -3/2 (since eˣ > 0)
        f''(x) = (2x + 5)eˣ. f''(-3/2) = 2·e^(-3/2) > 0 → minimum.

  Problem 4 — v(t) = t² - 5t + 4:
  - (a) v(0) = 4 m/s
  - (b) t² - 5t + 4 = 0 → (t - 1)(t - 4) = 0 → t = 1, t = 4
  - (c) a(t) = v'(t) = 2t - 5. a(3) = 6 - 5 = 1 m/s²
  - (d) s(t) = t³/3 - 5t²/2 + 4t + c. s(0) = 2 → c = 2.
        s(t) = t³/3 - 5t²/2 + 4t + 2
  - (e) v changes sign at t = 1 and t = 4.
        ∫₀¹ v dt = [t³/3 - 5t²/2 + 4t]₀¹ = 1/3 - 5/2 + 4 = 11/6
        ∫₁⁴ v dt = [t³/3 - 5t²/2 + 4t]₁⁴ = (64/3 - 40 + 16) - 11/6
                 = -8/3 - 11/6 = -27/6 = -9/2
        Total distance = 11/6 + 9/2 = 11/6 + 27/6 = 38/6 = 19/3 m
